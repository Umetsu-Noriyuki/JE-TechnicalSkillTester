# GAS 実装ルール & 注意事項
- TypeScript (`.ts`) で記述する。
- トランスパイルしたローカルの `.js` ファイルは、clasp によってプッシュされると自動的に GAS環境で解釈される。
- 既存コードを破壊せず、小さく安全に変更すること。
- 秘匿情報（APIキーなど）をコード内にハードコードせず、GASの `PropertiesService` などを活用するように提案すること。

## GAS特有の制限・非同期処理
- GAS特有の制限（実行時間制限の6分ルールなど）を考慮したコードを提案すること。
- `google.script.run` を使用した非同期通信の実装時は、成功時(`withSuccessHandler`)と失敗時(`withFailureHandler`)のハンドリングを漏れなく記述すること。

## 実行制限（CLIエージェント制約）
クラウド上の本番環境を誤って上書き・破壊することを防ぐため、以下のコマンドの自動実行は**厳格に禁止**します。
- `clasp push` （クラウド上のコードの上書き）
- `clasp deploy` （ウェブアプリ等のデプロイ）
- `clasp clone` または `clasp pull`
- npm start や npm run などの起動コマンド
デプロイや同期が必要な場合は、**必ず「ユーザーにコマンド（例: clasp push）の実行を依頼」**してください。

## MCPツールの使用ガイドライン
1. 仕様確認・ドキュメント検索（`google-knowledge`）
- **使用条件:** GAS固有のAPIの仕様確認やエラー解決に使用。推測で書かない。
- **検索時の注意:** 具体的なメソッド名で必要最小限のドキュメントを取得すること。一般的なJS文法には使用しない。
2. ユーザーデータの取得・操作（`gws`）
- **使用条件:** ユーザーから実データ（Gmail, Calendar, Drive等）へのアクセス指示があった場合のみ。
- **絶対禁止事項:** 明示的な承認なしにデータの削除・破壊的更新を行わない。取得した実データをコードにハードコードしないこと。
